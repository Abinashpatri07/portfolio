# Abinash Patri — Portfolio Website

A modern, high-performance developer portfolio built with **React (JavaScript)** and **Tailwind CSS**, designed after the aesthetic, structure, and engineering style of [the-yash.in](https://the-yash.in/#expertise).

## ✨ Features

- **Typography & Theme System**:
  - Warm minimalist background (`#f7f8f4`) with forest green accents (`#568b6d`, `#203a2d`).
  - Font styling with **Manrope** (bold headings), **Playfair Display** (editorial serif accents), and **DM Sans** (clean body text).
- **Navigation & Sticky Header**:
  - Frosted glass effect with active section detection and smooth scrolling.
  - Fully responsive mobile drawer navigation with touch-friendly layout.
- **Hero Section**:
  - Live availability status indicator with pulsing dot.
  - Prominent headline: *"Building software that makes complexity simple."*
  - Interactive CTAs and architectural core values.
- **01 / About Section**:
  - Philosophy & foundations highlighting automation-first thinking, system architecture, and enterprise security.
- **02 / Expertise Section** *(Target `#expertise`)*:
  - 7 engineering domain cards (Frontend, Backend, Databases, Cross-Platform, Real-Time, AI/ML, Cloud/DevOps).
  - Numbered index headers (`01 / 07`), Lucide icons, comprehensive copy, and tech stack tags.
- **03 / Selected Work (Projects)**:
  - Custom interactive visual mockups (School Governance, Health Camp Operations, Integrated Intercom, Customer 360 & AI Platform).
  - Category filters (`All`, `Web`, `Systems`, `AI & Data`), platform indicators, and key capabilities breakdown.
- **04 / Services**:
  - High-contrast forest green showcase of end-to-end services.
- **05 / Approach**:
  - 4-phase structured engineering workflow: *Understand → Architect → Build → Refine*.
- **06 / Get In Touch (Contact)**:
  - Interactive project inquiry form with preferred reply channel (Email/WhatsApp), multi-select service tags, budget selector, and timeline selector.
- **Ultra-Responsive Mobile View**:
  - Meticulously tested and optimized for mobile screens (touch targets, flexible layout, fluid typography, no horizontal overflow).

## 🚀 Getting Started

To run the development server locally:

```bash
npm run dev
```

The application will start on `http://localhost:3000`.

To build for production:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
